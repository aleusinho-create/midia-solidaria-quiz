# Quiz Solidário · Mídia Sol Mktg Solidário

Diagnóstico interativo que mede o **Nível de Solidariedade** de uma pessoa com base nos
princípios da Economia Popular e Solidária, do cooperativismo e do associativismo.

## Como funciona
- 12 perguntas em 5 dimensões (cooperação, autogestão, consumo, associativismo, justiça).
- Pontuação de 12 a 48, dividida em 5 níveis.
- Resultado personalizado + captura de e-mail + CTAs para o Blog, a Campanha
  Mídia Solidária e os serviços da Mídia Sol Mktg Solidário.

## Stack
- HTML + CSS + JavaScript puros (zero build, zero dependência).
- Hospedado via **GitHub Pages**.
